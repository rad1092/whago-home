# WHAGO

HongDae Kim의 개인 포트폴리오이자 제품 스튜디오의 첫 번째 웹사이트입니다.
검증된 작업과 현재 만드는 과정을 정적인 단일 페이지로 보여줍니다.

## Prerequisites

- Node.js `>=22.13.0`

## Local development

```bash
npm install
npm run dev
npm run build
```

## Commands

- `npm run build`: production build
- `npm test`: build and verify rendered HTML
- `npm run lint`: lint the source

The current site is static by design. It does not require authentication, D1, or
R2.
